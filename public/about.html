About MovieVerse

Discover. Explore. Enjoy.

MovieVerse is a modern full-stack movie discovery platform designed to help cinema enthusiasts explore movies, search across genres, and maintain a personalized list of favourite movies.

Explore Catalog View Java Architecture

Full-Stack Java + Tailwind

Engineered with clean enterprise layered architecture: Controllers, Services, Repositories, JPA Entities, and high-performance REST APIs.

Our Mission

To provide an intuitive, high-speed, and visually stunning movie portal that allows users to quickly search, filter, and curate cinematic masterpieces.

Key Features

  • • Instant dynamic search by title & cast
  • • Multi-genre filtering with active pills
  • • Complete movie metadata (Director, Cast, Date)
  • • Favourites watchlist with real-time sync

Clean Architecture

Adheres strictly to enterprise Java conventions: Spring Boot MVC, Spring Data JPA repositories, DTO transfers, custom exception handlers, and relational MySQL schemas.

Technology Stack Details

Backend

  • • Java 17 / Java 21
  • • Spring Boot 3.x
  • • Spring MVC (REST APIs)
  • • Spring Data JPA & Hibernate
  • • Spring Security (BCrypt Hashing)

Database

  • • MySQL 8.0+
  • • JPA Entities & Table Mappings
  • • Foreign Key Cascading
  • • SQL DDL Schema & DML Seeds
  • • Connection Pooling (HikariCP)

Frontend UI

  • • HTML5 & Semantic Web
  • • Tailwind CSS Utilities
  • • Bootstrap Icons (1.11+)
  • • Dark Cinematic Visual Theme
  • • Fully Responsive Grid

Client Engine

  • • Vanilla JavaScript (ES6+)
  • • Fetch API Async/Await
  • • JSON Payloads & DTOs
  • • Local Storage Session State
  • • Skeleton Loaders & Toast Alerts
